# Changelog

## 0.3.0 — Canonical transcript arguments

- Проанализированы первые пять канонических транскриптов канала «Взгляд из Четвертого Измерения».
- Добавлены 11 аргументов Александра с посылками, возражениями, ответами, оговорками, уверенностью интерпретации и точными таймкодами.
- Добавлена вкладка «Аргументы» и переходы между аргументами, событиями, графом и AI-помощником.
- Добавлены события о Декларации суверенитета Украины, распаде СССР, Мюнхенской речи 2022 года и операции «Паутина».
- Добавлены концепты стратегического эффекта, защиты гражданских, общей истории, целей войны, правопродолжательства и общественной распространённости идеологии.
- Проверка данных расширена на аргументы, канонические транскрипты и все новые ссылки.

## 0.2.0 — React foundation

- Перенесён автономный прототип временной шкалы в Vite + React + TypeScript.
- Вкладка «Временная шкала» переименована в «Хроно».
- Добавлена интерактивная вкладка «Связи» на React Flow.
- Добавлена AI-вкладка: согласие на анализ, микрофонный транскрипт там, где браузер поддерживает Web Speech API, ручной ввод, демонстрация, локальное обнаружение тем и три типа ответа.
- Сохранены 13 стартовых событий, статьи, источники и медиассылки.
- Добавлены RU / EN / UA и светлая / тёмная темы.
- Добавлены GitHub Pages workflow, проверка данных, базовые тесты и документация для дальнейшей разработки.
- Зафиксировано разделение прямых, документированных и интерпретационных связей.
