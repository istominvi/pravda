# Changelog

## 0.4.1 — Chronological article numbering

- Каталог статей и переходы «предыдущая/следующая» переведены на хронологический порядок.
- Номера статей вычисляются из текущей позиции и автоматически пересчитываются при вставке более раннего материала.
- Понятия и аргументы сортируются по ближайшему датированному узлу, но эта дата явно обозначается как контекст, а не как дата возникновения.
- Стабильные URL продолжают использовать идентификатор статьи и не зависят от меняющегося номера.

## 0.4.0 — Unified articles

- Вкладка «Аргументы» заменена единым каталогом «Статьи» с поиском, фильтрацией по типу и пагинацией.
- Каждый из 68 узлов графа автоматически стал статьёй с тем же идентификатором: события, документы, понятия и аргументы больше не образуют параллельные наборы.
- Хроно, Связи и AI-помощник переведены на единые маршруты `/articles/:id`; старые ссылки перенаправляются.
- Статьи событий и аргументов сохраняют специализированный полный разбор, а статьи понятий показывают входящие и исходящие связи, доказательный статус и связанные источники.
- Добавлена проверка полного совпадения реестра статей и узлов графа.

## 0.2.0 — React foundation

- Перенесён автономный прототип временной шкалы в Vite + React + TypeScript.
- Вкладка «Временная шкала» переименована в «Хроно».
- Добавлена интерактивная вкладка «Связи» на React Flow.
- Добавлена AI-вкладка: согласие на анализ, микрофонный транскрипт там, где браузер поддерживает Web Speech API, ручной ввод, демонстрация, локальное обнаружение тем и три типа ответа.
- Сохранены 13 стартовых событий, статьи, источники и медиассылки.
- Добавлены RU / EN / UA и светлая / тёмная темы.
- Добавлены GitHub Pages workflow, проверка данных, базовые тесты и документация для дальнейшей разработки.
- Зафиксировано разделение прямых, документированных и интерпретационных связей.
